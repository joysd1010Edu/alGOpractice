
# 1. টাইপস্ক্রিপ্টে any, unknown এবং never টাইপ

টাইপস্ক্রিপ্টের টাইপ সিস্টেম শক্তিশালী হলেও, এটি মাঝে মাঝে ভুলভাবে বোঝা হয়। এর সবচেয়ে বিভ্রান্তিকর তিনটি টাইপ—any, unknown, এবং never—প্রায়শই ডেভেলপারদের বিভ্রান্ত করে। 


__**1. 'any' Type:**__ এমন একটি টাইপ যা টাইপ চেকিং নিষ্ক্রিয় করে। এটি কোনো টাইপ রুল ছাড়াই সমস্ত ডেটা টাইপের অনুমতি দেয়।

- **ব্যবহার:** জাভাস্ক্রিপ্ট কোডবেস মাইগ্রেট করার সময় বা ডাইনামিক ডেটা নিয়ে কাজ করার সময়, যেখানে টাইপ সেফটি নিশ্চিত করা হয় না।

- **সুবিধা:** আমরা যেকোনো কিছুকে any-তে অ্যাসাইন করতে পারি।

- **অসুবিধা:** টাইপ সেফটি নষ্ট হয়: ত্রুটি শুধুমাত্র রানটাইমে দেখা যেতে পারে। 



__**2. The never Type:**__ এটি এমন একটি Value কে বোঝায় যার টাইপ এখনও জানা যায়নি।

- **ব্যবহার:** যখন type safety সাথে flexibility  প্রয়োজন হয়।

- **সুবিধা:** ডিফেন্সিভ প্রোগ্রামিংয়ে সাহায্য করে।

- **অসুবিধা:** টাইপ গার্ড বা অ্যাসারশনের মাধ্যমে সুস্পষ্ট narrowing  প্রয়োজন হয়।


__**2. The unknown Type:**__ 
এটি এমন মানগুলিকে বোঝায় যা কখনই থাকা উচিত নয়। এটি এমন ফাংশন বা এক্সপ্রেশনের জন্য ব্যবহৃত হয় যা একটি valid  ফলাফল তৈরি করতে পারে না।

- **ব্যবহার:** Exhaustive checks এ সমস্ত সম্ভাব্য ক্ষেত্রগুলি পরিচালনা করা হয়েছে তা নিশ্চিত করতে, Unreachable code এ এটি নির্দেশ করে যে logic এ একটি নির্দিষ্ট branch যা কখনই থাকা  উচিত নয়।

- **সুবিধা:** Logical error detection, Union completeness.

- **অসুবিধা:** এর অপব্যবহার কোডকে পড়া ও বোঝা কঠিন করে তুলতে পারে।

# 2.Interfaces vs. Types in TypeScript

__**Interfaces Definition:**__ টাইপস্ক্রিপ্টে একটি ইন্টারফেস হলো কোনো অবজেক্টের গঠন বর্ণনা করার একটি উপায়। এটি একটি অবজেক্টের must have প্রোপার্টি এবং মেথডগুলোকে সংজ্ঞায়িত করে, কিন্তু সেগুলো কীভাবে ইমপ্লিমেন্ট করা হবে তা নির্দিষ্ট করে না। 

```ts
interface User {
    id: number;
    name: string
    email?: string; 
}

const user: User = { id: 1, name: "Joy", email: "joy@example.com" }; 
console.log(user);
```

- **সুবিধা:** 
  - Extendable
  - Inheritance
  - Optional properties
  - Readonly properties
  - Declaration merging
  - Readable and intuitive
  - Supports inheritance



- **অসুবিধা:** সীমিত Scope, ইন্টারফেস মূলত অবজেক্ট কাঠামো বর্ণনা করার জন্য ব্যবহৃত হয়। এগুলো সরাসরি ইউনিয়ন, ইন্টারসেকশন বা প্রিমিটিভ টাইপ উপস্থাপন করতে পারে না।

__**Type Aliases Definition:**__ টাইপস্ক্রিপ্টে টাইপ অ্যালিয়াস যেকোনো টাইপকে (প্রিমিটিভ, ইউনিয়ন, ইন্টারসেকশন, ইত্যাদি) একটি নাম দেওয়ার উপায়। 

```ts
type User = {
    id: number;
    name: string;
    email?: string;
};

const user: User = { id: 1, name: "Joy", email: "joy@example.com" };
console.log(user);

```

- **সুবিধা:** 
    - অবজেক্ট ছাড়াও প্রিমিটিভ, ইউনিয়ন, ইন্টারসেকশন, টাপল ইত্যাদি বর্ণনা করতে পারে।

    - Complex টাইপ তৈরি করা যায়।

    - Conditional এবং mapped টাইপের সাথে কাজ করতে পারে।

    - কোডকে আরও সহজবোধ্য করে।



- **অসুবিধা:** Declaration merging নেই, একই নামে একাধিক টাইপ alias তৈরি করলে error হবে।  Interfaces এর মতো extend বা merge করা যায় না।
